# 🤖 Telegram Bot Template

Многофункциональный Telegram-бот с интерактивным меню, погодой и комплиментами.

## 🚀 Возможности

- **Приветствие** — персонализированное сообщение с именем пользователя
- **Время и дата** — команды `/time` и `/date`
- **Комплименты** — случайные позитивные сообщения по кнопке
- **Погода** — интеграция с OpenWeatherMap API (команда `/weather <город>` или кнопка `🌤️ Погода`)
- **Интерактивное меню** — клавиатура с кнопками для быстрого доступа
- **Обработка текста** — бот отвечает на любые сообщения

## 🛠️ Технологии

- **Python 3.12**
- **pyTelegramBotAPI**
- **OpenWeatherMap API**
- **Telegram Bot API**
